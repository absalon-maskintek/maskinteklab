# Maskinteklab – Absalon Kalundborg

Opsætning, kode og vejledninger til udstyret i maskinteknologi-laboratoriet på Absalon i Kalundborg.

Repoet er studenterdrevet og ikke en officiel Absalon-side.

## Indhold

| Mappe | Indhold |
| --- | --- |
| [`labcomputer/`](labcomputer/) | Lab-PC'en `MASKINTEKLAB-1`: [sådan genskaber du maskinen](labcomputer/opsaetning.md), Firefox-opsætning og startfil til Node-RED |
| [`node-red-flows/`](node-red-flows/) | Node-RED-flows til LabJack T7, én fil pr. opstilling |

Er lab-PC'en gået i stykker eller blevet nulstillet, så start med [labcomputer/opsaetning.md](labcomputer/opsaetning.md).
