# Node-RED-flows

Flows til LabJack T7, én JSON-fil pr. opstilling.

**Eksportér:** Menu → Export → All flows → Download

**Importér:** Menu → Import → vælg filen → Import → Deploy

Fjern den gamle opstilling, før en ny importeres. Modbus-klienten følger med i hver fil, og vælger man "Import copy", får T7'eren en ekstra forbindelse. Den kan kun holde to ad gangen.

Installation af Node-RED og palette står i [opsætningen af lab-PC'en](../labcomputer/opsaetning.md#8-nodejs-og-node-red).
